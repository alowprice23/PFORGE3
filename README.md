# pForge

pForge is an AI-powered code repair and refactoring engine. It uses a suite of specialized agents to analyze codebases, identify issues, and propose solutions. The system is designed to be run locally, without the need for a Docker container.

## Features

*   **Agentic System:** A team of specialized AI agents that collaborate to solve complex code problems.
*   **Mathematical Efficiency Formula:** A formula that governs the system's decision-making process, ensuring that it always works on the most important tasks.
*   **Local-First:** Designed to run entirely on your local machine, without the need for Docker or other complex setups.
*   **Conversational CLI:** An interactive command-line interface that allows you to interact with the system in natural language.
*   **Extensible:** The system is designed to be easily extended with new agents and capabilities.

## Getting Started

To get started with pForge, you'll need to have Python 3.11+ and Node.js 20+ installed.

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/alowprice23/PFORGE.git
    cd PFORGE
    ```
2.  **Install dependencies:**
    ```bash
    pip install .
    ```
3.  **Run the tests:**
    ```bash
    pytest tests/
    ```
4.  **Start the CLI:**
    ```bash
    pforge --help
    ```
